

# 🛍️ Vrinda Store – Sales & Order Data Analysis

## 📌 Introduction
This project presents an end-to-end analysis of **Vrinda Store's** e-commerce sales data, covering over **31,000 orders**. The workbook explores monthly sales trends, customer demographics, order fulfillment performance, and state-wise revenue distribution — all consolidated into a single interactive Excel dashboard.

---

## 🗂️ Workbook Structure

| Sheet | Purpose |
|---|---|
| `Vrinda Store` | Raw transactional dataset (31,000+ orders) |
| `sales vs order on months basis` | PivotTable of monthly sales amount & order count |
| `men vs women` | PivotTable of sales split by gender |
| `order status` | PivotTable of order fulfillment outcomes |
| `Sheet7` | PivotTable of revenue by shipping state |
| `final report for vrindha store` | Final visual dashboard — **Vrinda Store Annual Report 2026** |

---

## 📊 Dataset Overview
Each record includes: Order ID, Customer ID, Gender, Age, Age Group, Order Date, Status, Sales Channel, SKU, Category, Size, Quantity, Amount, and full shipping address (city, state, postal code, country).

---

## 📈 Key Insights

- **Sales Trend:** Monthly sales peaked in **March (₹19.28L)** and gradually declined toward the year-end, dropping to **₹16.15L in November**.
- **Gender Split:** **Women account for ~64% of sales revenue** (₹1.36 Cr) vs. Men at ~36% (₹76.1L).
- **Order Fulfillment:** **92% of orders were successfully delivered**, with only small fractions Cancelled (3%), Returned (3%), and Refunded (2%).
- **Top States by Revenue:** **Maharashtra (₹29.9L)**, **Karnataka (₹26.5L)**, and **Uttar Pradesh (₹21.0L)** are the top-performing regions.
